COMAVI supporting information
=============================

Eleven supporting-information items. Upload each file below to PLOS Computational Biology as a separate
Supporting Information item, using the item name in the first column. Their captions are listed at the end
of the manuscript file, as PLOS requires, and are not uploaded separately. Supporting information is
published as provided, so every workbook sheet opens on its own caption row and every text item opens on a
contents table. Bracketed numbers in these files refer to the main article's reference list.

  item       file              title
  ------------------------------------------------------------------------------------------------
  S1 Table   S1_Table.xlsx     Benchmark cohort, evidence and comparator tables. (21 KB)
  S2 Table   S2_Table.xlsx     Operating points, evidence states and robustness tables. (15 KB)
  S3 Table   S3_Table.xlsx     Committed structural expectations with their evidence basis and citation. (14 KB)
  S1 Text    S1_Text.docx      Implementation details, statistical conventions and evidence provenance. (38 KB)
  S2 Text    S2_Text.docx      Sensitivity analyses, mechanism-class decomposition and operating-point diagnostics. (39 KB)
  S3 Text    S3_Text.docx      Pathogenicity comparison, robustness and independent validation. (39 KB)
  S1 Fig     S1_Fig.tif        Stress tests of the mechanism-pattern score. (477 KB)
  S2 Fig     S2_Fig.tif        Binding-axis validation on SKEMPI 2.0. (275 KB)
  S3 Fig     S3_Fig.tif        Structural-context comparators on the 47-variant prioritization population. (173 KB)
  S4 Fig     S4_Fig.tif        Priority-score transformation and component ranking. (307 KB)
  S5 Fig     S5_Fig.tif        Call relationships between predicted and measured energies at 2.5 kcal/mol. (120 KB)

The five SI figures are 600 dpi LZW TIFF files written by figures/submission/make_submission_figures.py;
figures/submission/SHA256SUMS.txt pins them, so any of them can be regenerated and checked. SI_INDEX.csv lists
every sheet and section with its title. It is a repository record and is not uploaded.
