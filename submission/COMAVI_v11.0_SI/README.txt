COMAVI supporting information
=============================

Ten supporting-information items. Upload each file below to PLOS Computational Biology as a separate
Supporting Information item, using the item name in the first column. The captions are listed at the end of
the manuscript file, as PLOS requires; they are not repeated here and must not be uploaded separately.

Supporting information is published exactly as provided and is not copyedited, so each file is
self-describing: every workbook sheet opens on its own caption row and every document on a contents table.

  item       file             what it contains
  ----------------------------------------------------------------------------------------------
  S1 Table   S1_Table.xlsx    Committed structural expectations with their evidence basis and citation. (15 KB)
  S2 Table   S2_Table.xlsx    Benchmark cohort, evidence and comparator tables. (23 KB)
  S3 Table   S3_Table.xlsx    Operating points, evidence states and robustness tables. (18 KB)
  S1 Text    S1_Text.docx     Implementation details, statistical conventions and evidence provenance. (41 KB)
  S2 Text    S2_Text.docx     Sensitivity analyses, mechanism-class decomposition and operating-point diagnostics. (42 KB)
  S3 Text    S3_Text.docx     Pathogenicity comparison, robustness and independent validation. (40 KB)
  S1 Fig     S1_Fig.tif       Binding-axis validation on SKEMPI 2.0. (276 KB)
  S2 Fig     S2_Fig.tif       Call relationships between predicted and measured energies at 2.5 kcal/mol. (119 KB)
  S3 Fig     S3_Fig.tif       Structural-context comparators on the 46-variant prioritization population. (165 KB)
  S4 Fig     S4_Fig.tif       Priority-score transformation and component ranking. (310 KB)

Items are numbered in the order the manuscript first cites them. The four figures are 600 dpi LZW TIFFs
written by figures/submission/make_submission_figures.py and pinned in figures/submission/SHA256SUMS.txt, so
any of them can be regenerated and checked. The three workbooks are written from the committed records by
scripts/build_supplement.py, and the three texts from their sources by scripts/build_si_texts.py.
SI_INDEX.csv lists every sheet and section with its title; it is a repository record and is not uploaded.
