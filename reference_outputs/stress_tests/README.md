# COMAVI canonical stress-test outputs

These files were generated by `verification/stress_tests.py` from
`reference_outputs/scored_61var_canonical.csv`.

The primary continuity population excludes the two BRCA1-BRCT variants whose
curated mechanism is not observable in the deposited structure. It therefore
contains the 56 graded benchmark variants and their applicable structural
outputs.

Since v11 the label permutation and the variant bootstrap run on the 56
benchmark rows only. Permuting ground-truth profiles across all 61 scored rows
handed benchmark profiles to the calls of the five excluded candidates, and
resampling 61 rows let the number of graded variants vary. Leave-one-system-out
and the system-cluster bootstrap still use the full table, from which the
excluded candidates drop out because they are never graded.

Values are not quoted here, because quoted values go stale when the ground
truth or the grader changes (they did at v8.0 and again at v11, when the grader
was brought into line with the published rubric). Read them from the records:

- `comavi_stress_tests.csv`: permutation null, leave-one-system-out range,
  replicate noise, variant and system-cluster bootstrap intervals;
- `COMAVI_stress_verified_statistics.json`: the same intervals at full
  precision, with the population definition.

`COMAVI_stress_verified_statistics.json` records the full-precision intervals,
population definition, random seed, system labels, and SHA-256 hashes of the
canonical table, stress-test script, summary table, and raw draw archive.

Regeneration command:

    python verification/stress_tests.py \
      --canonical reference_outputs/scored_61var_canonical.csv \
      --scripts-dir scripts \
      --out-dir PATH_TO_OUTPUT_DIRECTORY \
      --n-perm 2000 \
      --n-noise 500 \
      --n-boot 2000
