`reference_outputs/scored_61var_canonical.csv`.

curated mechanism is not observable in the deposited structure. It therefore
contains 57 whole-variant mechanism grades and 132 applicable structural
outputs.

- primary structural agreement is 99/132 = 0.7500;

- system-cluster SA 95% CI is [0.696, 0.818];
- the cluster bootstrap resamples 14 systems for 2,000 draws with seed 8.

The separate all-row denominator audit is 99/133 = 0.7444. That population is
not the population bootstrapped in `comavi_stress_tests.csv`.

`COMAVI_stress_verified_statistics.json` records the full-precision intervals,
population definition, random seed, system labels, and SHA-256 hashes of the
canonical table, stress-test script, summary table, and raw draw archive.

      --canonical reference_outputs/scored_61var_canonical.csv \
      --scripts-dir scripts \
      --out-dir PATH_TO_OUTPUT_DIRECTORY \
      --n-perm 2000 \
      --n-noise 500 \
