# Maintainer records

This directory contains release, recovery, and repository-administration notes.
These files are retained for provenance but are not part of the COMAVI user
workflow and are not required to reproduce results.

- [`COMAVI_public_release_handoff.md`](COMAVI_public_release_handoff.md) — archived
  public-release and history-recovery record. Commit IDs and push instructions in
  that record describe its original checkpoint, not the current repository state.

User-facing documentation starts at [`docs/README.md`](../README.md).
